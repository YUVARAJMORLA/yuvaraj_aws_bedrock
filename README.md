# AWS Bedrock Projects & GenAI Applications

A collection of AWS Bedrock projects, experiments, and GenAI applications. Built using different AWS services and updated with the latest SDKs and APIs for 2026.

## Applications & Projects

- **[rag_app](./rag_app)**: Multimodal Document RAG (PDF, DOCX, PPTX, XLSX) with **Amazon Titan Embeddings** and **Meta Llama 4**, alongside real-time voice streaming with **Amazon Nova 2 Sonic**.
